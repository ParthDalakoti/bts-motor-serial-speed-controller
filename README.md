## ⚡ Executive Engineering Summary
Serial Terminal ASCII Command Motor Speed & Dynamometer Controller using BTS7960 High-Current Driver. This project is an independent engineering system designed, built, and tested by **Parth Dalakoti** during his B.Tech in Electronics & Communication Engineering.

## 🚀 How to Build & Flash
1. Open the source code in [`firmware/`](firmware/) using **Arduino IDE** or **VS Code PlatformIO**.
2. Select target board: `Arduino Nano`.
3. Configure serial baud rate (115200 or 9600 baud as defined in firmware).
4. Connect board and flash.
